# nig-drives 1.6 plan (draft, 2026-11-07)
Base: v1.5.0c @ 5013a63, /home/nig/nig-drives on nigian. Not started; waiting on Nigel's go.
Source: Nigel's 1.5.0c playtest 2026-11-07 + nav/autopilot asks.

## 1.6a  Map that doesn't run out (do first; nav depends on it)
- Find and fix the tile loading hole near Columbia St (King St N and Westmount Rd both end there).
- Wellington St -> Hwy 85/86 interchange must load and connect (ramps, links, overpasses).
- Retry/refill failed or partial tiles in the background; never leave a permanent gap. Small "loading" marker where a tile is pending.
- Larger, persistent cache (IndexedDB now; disk in the Electron build later). First step toward "let it grow its own map".
- Test spots: King/Columbia, Westmount/Columbia, Wellington to 85/86 to St Jacobs, Kitchener home area.

## 1.6b  Road edges and scale
- Smooth kerb/shoulder blend into terrain; stop cars launching off rough edges.
- Speed check: compare displayed km/h with real distance covered over time for every car (bus at 80 looks right, Golf at 140 seems slow). Fix whatever disagrees (speed source, gearing, camera).

## 1.6c  Nav HUD (the important one)
- Always-on strip near the speedometer: compass heading (e.g. NE 45 deg) + current street.
- Big street sign only on turning onto a new street; upcoming side streets named at intersections.
- Expandable minimap to full map with street names (Nigel asked; names OK here).
- Start point: home / address / map pick / current spot. Destination by address.
- TomTom geocoding + routing (existing key). Route line on map, turn-by-turn, distance to next turn, ETA, reroute on missed turn.
- Prefetch map tiles along the route.

## 1.6d  Autopilot + sim speed
- Autopilot drives the route: steering, braking, lane keeping, speed limits, stops/signals as data allows.
- Profiles like Tesla: Chill / Standard / Hurry.
- Sim speed 1x-16x on full physics; above 16x a route-follow mode with lighter physics/loading, full sim returns at 1x or on takeover.
- Example: home in Kitchener -> address in Montreal.

## 1.6e  Slew mode (Y key)
- Pause physics, free move/rotate/raise with variable rate; exit drops onto nearest road with chosen heading. Doubles as start-point picker.

## Later (not 1.6)
- 1.8+: photoreal / street-view-type scenery (Google Photorealistic 3D Tiles via Cesium) in the Windows executable with an unlimited on-disk cache that grows its own map. Check Google storage terms first.
- ~1.8: career mode.
- Smaller carry-overs: second gamepad picker, handbrake pad bind, steer deadzone/sensitivity, OEM suspension tables, in-world tutorial.
